## Overview

This guide explains how partners can connect an existing VAPI agent to a customer.

## Prerequisites

- Access to the customer account
- VAPI agent identifier (and required permissions)

## Steps

1. Open the customer’s **Agents** section.
2. Choose **VAPI**.
3. Select **Import agent**.
4. Enter the VAPI agent details and confirm.

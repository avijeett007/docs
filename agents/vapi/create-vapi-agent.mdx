## Open the agent setup

1. Open the **VAPI Agents** page in the Partner Portal.
2. Click **Create Agent**.
3. Choose the customer who will own the agent, then click **Next**.

![Create VAPI Agent window showing Customer, Knowledge Base, Basic Settings, Advanced Settings, and Function Calls](/images/screenshots/vapi-create-production-2026-09-12.png)

## Complete the setup

The current setup includes five sections:

1. **Customer** — assign the agent to the correct customer.
2. **Knowledge Base** — choose the information the agent can use.
3. **Basic Settings** — add the agent's name, voice, opening message, and instructions.
4. **Advanced Settings** — fine-tune call behaviour only when needed.
5. **Function Calls** — choose connected tools when available.

Review the details before saving. After creation, return to the VAPI Agents page to find the agent and manage its customer assignment or webhook.

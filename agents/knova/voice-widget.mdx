## What the widget does

The voice widget lets website visitors speak with an AI agent from their browser. The browser asks for microphone access when a visitor starts a conversation.

## Create a widget

1. Open **AI Agents** and choose the agent you want to use.
2. Open the agent's actions menu and select **Manage Widgets**.
3. Select **Create Widget**.
4. Enter a name and add the website domains where the widget may appear.
5. Choose the launcher style, position, colour, label, and session length shown in the form.
6. Save the widget.

## Add it to a website

Copy the embed code provided by the portal and add it to the website pages where you want the launcher to appear. Use the generated code as-is so it stays linked to the correct widget.

Test the widget on an allowed domain before publishing the page.

## Update or disable a widget

Open **Manage Widgets** from the agent's actions menu. You can edit the displayed settings, copy the embed code again, or turn the widget off.

If a visitor sees an unavailable message, confirm that the widget and agent are active and that the current website is included in the allowed domains.

<Tip>
After changing the widget's appearance or welcome text, reload the test page before checking the result.
</Tip>

## Before you begin

You need an active Telnyx account, at least one phone number in that account, and a Telnyx API key with the access required by the import form.

## Import numbers

1. Open **Phone Numbers** in the Partner Portal.
2. Select **Import Numbers**.
3. Choose **Telnyx**.
4. Enter the requested account details.
5. Select the numbers you want to import.
6. Confirm the import.

Imported numbers appear in the Phone Numbers list with **Telnyx** shown as the provider.

## Assign a number

1. Find the imported number in the list.
2. Open its actions menu and select **Assign Agent**.
3. Choose the customer and AI agent shown in the form.
4. Select the available call direction options.
5. Save.

The available inbound and outbound options depend on the selected agent. Follow the choices shown in the assignment form.

## Outbound calling for UK and EU numbers

Telnyx phone numbers with UK (+44) or EU country codes connect through Telnyx's global SIP routing by default. This is the correct setting for most accounts — regional routing (e.g. `europe.sip.telnyx.com`) is not necessary and was the cause of outbound calls never connecting for UK/EU BYO numbers.

If you imported a UK or EU Telnyx number before October 2026 and outbound calls did not connect, the fix is already live — no action is required. Existing numbers that were stuck due to the previous routing are now able to be re-assigned normally.

## Troubleshooting

- If no numbers appear, confirm that the API key belongs to the correct Telnyx account and has the required access.
- If assignment fails, confirm that the number and agent are active, then try again.
- If the needed call direction is unavailable, review the agent's configuration or contact support.
- If a number shows status **Cleanup pending** and cannot be reassigned, wait a few minutes and refresh **Phone Numbers**. If the status does not clear after several minutes, contact support.
- For international outbound calls, confirm that the destination country is available in your Telnyx account before testing.
- If outbound calls from a UK or EU number fail to connect, verify the number is active in your Telnyx dashboard and that the outbound voice profile is correctly attached. Global SIP routing is used by default and does not require any configuration change on your part.

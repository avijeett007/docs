## Before you begin

You need an active Telnyx account, at least one phone number in that account, and a Telnyx API key with the access required by the import form.

## Import numbers

1. Open **Phone Numbers** in the Partner Portal.
2. Select **Import Numbers**.
3. Choose **Telnyx**.
4. Enter the requested account details.
5. Select the numbers you want to import.
6. Confirm the import.

Imported numbers appear in the Phone Numbers list with **Telnyx** shown as the provider.

## Assign a number

1. Find the imported number in the list.
2. Open its actions menu and select **Assign Agent**.
3. Choose the customer and AI agent shown in the form.
4. Select the available call direction options.
5. Save.

The available inbound and outbound options depend on the selected agent. Follow the choices shown in the assignment form.

## Troubleshooting

- If no numbers appear, confirm that the API key belongs to the correct Telnyx account and has the required access.
- If assignment fails, confirm that the number and agent are active, then try again.
- If the needed call direction is unavailable, review the agent's configuration or contact support.

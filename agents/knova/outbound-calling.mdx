## Before you begin

You need:

- an active Knova agent configured for outbound calls;
- a voice-capable phone number; and
- enough AI and telephony credits for a test call.

The Knova Agents list shows each agent's type and channel. Use an agent marked **Outbound** and **Telephony**.

## Assign a phone number

1. Open **Phone Numbers**.
2. Find the number you want the agent to use.
3. Open the number's actions menu and select **Assign Agent**.
4. Choose the Knova agent and the outbound option shown in the form.
5. Save.

If the assignment form does not offer outbound calling, open the agent's configuration and check its type before trying again.

## Run a test call

1. Open **AI Agents → Knova Agents**.
2. Open the outbound agent's actions menu.
3. Select **Test Outbound Call** when available.
4. Enter a destination number in international format, including the country code.
5. Add any optional values requested by the form, then start the call.

Use a number you control for the first test. Confirm the agent speaks as expected and the correct caller ID appears before using the agent in a campaign.

## Use the agent in a campaign

Open **Campaigns**, create a campaign, and choose the outbound agent during setup. Follow the campaign review screen before starting calls.

## Troubleshooting

- **The outbound test action is missing:** confirm the agent is active and configured for outbound telephony.
- **The call does not start:** confirm the phone number is assigned to the agent and both credit balances are available.
- **The wrong caller ID appears:** check the assigned phone number before retrying.
- **A provider error appears:** review the provider account and number status, then contact support if the issue continues.

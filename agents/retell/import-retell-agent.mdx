## Overview

This guide explains how partners can connect an existing Retell agent to a customer.

## Prerequisites

- Access to the customer account
- Retell agent identifier (and required permissions)

## Steps

1. Open the customer’s **Agents** section.
2. Choose **Retell**.
3. Select **Import agent**.
4. Enter the Retell agent details and confirm.

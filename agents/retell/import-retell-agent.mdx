## Before you start

Have your Retell API key ready. Keep this key private and paste it only into the secure import window.

## Import agents

1. In the Partner Portal, open **AI Agents → Retell Agents**.
2. Click **Import Agents**.
3. Paste your **Retell API Key**.
4. Click **Fetch Retell Agents**.
5. Select the voice agents you want to add.
6. Click **Import**.

![Import Retell Agents window with the API key field and Fetch Retell Agents button](/images/screenshots/retell-import-production-2026-09-12.png)

After the import, open an agent to assign it to a customer or review its settings.

## Troubleshooting

- **The Fetch button is unavailable:** enter the API key first.
- **The key is rejected:** copy a current key from Retell and try again.
- **An agent is missing:** confirm it is a Retell voice agent and refresh the list.
- **The agent is already present:** return to the Retell Agents page and search for it by name.

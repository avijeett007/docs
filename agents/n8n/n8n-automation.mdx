## What N8N Automation is for

N8N Automation connects Knotie AI with N8N so you can build workflows like:

- Lead routing
- Customer follow-ups
- CRM updates
- Automated support flows

## Where to find it

1. Open **Manage AI Agents**.
2. Click **N8N Automation**.

## Create an authentication token

Tokens let you give a customer-scoped connection to N8N.

1. Open **N8N Automation**.
2. Click **Create Token**.
3. Choose the customer.
4. Save.

## Manage existing tokens

1. From **N8N Automation**, click **Manage Tokens**.
2. Review token scope, expiry, and usage limit.

## Install the Knotie node in N8N

The page links to the N8N community node:

- `n8n-nodes-knotie`

After installing it, you can set up credentials in N8N using your token.

## Getting started checklist

1. Install the Knotie node.
2. Create a token for a customer.
3. Configure credentials in N8N.
4. Run a test workflow.

## What Ultravox agents are in Knotie AI Pro

Ultravox is one of the supported voice AI providers in Knotie AI Pro.

Inside the Partner Portal you can manage Ultravox agents the same way you manage other providers:

- Import existing agents
- Create new agents
- Map agents to customers
- Test agents
- Configure webhooks and analytics

## Where to find it

1. Open **Manage AI Agents**.
2. Click **Manage Ultravox Agents**.

## Import agents

1. Click **Import Agents**.
2. Follow the import modal.
3. When import completes, refresh the page if needed.

Tip: If you see an upgrade prompt, your plan may not include Ultravox agents.

## Create a new agent

1. Click **Create Agent**.
2. Fill in the agent settings.
3. Save.

## Map an agent to a customer

Mapping links an agent to a customer record.

1. Open the agent’s actions menu.
2. Choose **Map to Customer** (or the equivalent mapping action).
3. Select the customer.
4. Set your **profit multiplier** (markup).
5. Save.

## Test an agent

1. Click **Test** on the agent.
2. Follow the test modal to run a sample call.

## Webhooks and analytics

If your page shows webhook settings:

- Enable webhook tracking so **Agent Analytics** can report accurate usage.

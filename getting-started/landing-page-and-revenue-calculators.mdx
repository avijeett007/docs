## Overview

The Knotie AI Pro homepage (`knotie-ai.pro`) has been redesigned as a full **scroll-film experience** built with GSAP and Lenis. When you scroll, the page plays like a film: the canvas globe on the hero animates through six chapters that tell the platform's story.

Below the scroll film, the page continues into a full conversion stack — the Revenue Playground, Dashboard Demo, How-it-works, integrations, testimonials, and a free-first **Start Free** section.

## Scroll-film hero

The hero section pins to the viewport while you scroll, playing a six-chapter narrative across the globe canvas. Each chapter transitions automatically as you move through the pinned section.

| Chapter | What you see |
|---|---|
| **1 · Hero** | The globe spins with the headline and CTAs front and center |
| **2 · Vendor chaos** | The globe fragments — animated tiles scatter to represent using a dozen disconnected tools |
| **3 · One platform** | Category rings snap together — everything converges onto a single globe |
| **4 · White-label reskin** | The browser chrome updates with your brand, the URL bar types your domain, and the globe sweeps your brand colours |
| **5 · Margin counter** | A live counter ticks from 15 % → 74 % margin as the globe locks in |
| **6 · Dashboard dock** | The globe shrinks and docks into the logo slot of a mock dashboard |

The hero uses pure CSS transforms and opacity mutations — no React re-renders happen during the scroll, so the animation runs at 60 fps even on mid-range hardware.

### Accessibility

- **`prefers-reduced-motion`** — if the visitor's OS has reduced motion enabled, the hero renders as a static stacked layout instead of the animated film.
- **No JavaScript / SSR** — the page ships all copy as server-rendered HTML. If JavaScript is disabled, a static fallback layout is shown.

## Free-first strategy — Start Free section

The v2 homepage adopts a **free-first** model. There is no pricing-tier wall on the homepage. Instead, the primary CTA leads to the **Free Forever** plan so users can start immediately, then expand their usage naturally as they grow.

### Free Forever card

| What's included | Notes |
|---|---|
| Core partner portal access | Full feature set at no charge |
| Card verification | Required for anti-bot verification only — your card is **never charged** |
| Usage-based expansion | Pay only for what your customers use as they grow |

The card copy is accurate: a payment method is required for identity verification, but no charge is made on sign-up.

### Partner Journey — Level System

Below the Free Forever card, the **Partner Journey** rail shows a gamified progression path:

| Level | Label | What you unlock |
|---|---|---|
| L1 | Getting started | Portal access, basic agent setup |
| L2 | First customer | Onboard your first paying customer |
| L3 | Scaling | Team features, more agents, higher limits |
| L4 | Agency | White-label, custom domains, reseller tools |
| L5 | Enterprise | Priority support, dedicated resources |
| L6 | Platinum partner | Custom commercial terms, co-marketing |

Each level has actions, credit/badge rewards, and unlocks. Progress through levels by completing actions in the platform — it's visible in your partner dashboard.

## Revenue Playground

The **Revenue Playground** section lets visitors model their income before signing up. It contains eight independent calculators, each on its own card.

| Calculator | What you model |
|---|---|
| Voice AI | Customers × minutes × resale price |
| Chat AI | Customers × messages × resale price |
| API Gateway | Token volume × margin |
| VPS Reselling | Servers × resale price |
| CRM SaaS | Customers × subscription price |
| Business Audit | Audits per month × fee |
| AI Receptionist | Receptionists × monthly fee |
| Custom Workflows | Projects × project fee |

## Rollback

The v2 landing page is controlled by a build-time flag. If a rollback is needed:

1. Set `NEXT_PUBLIC_FEATURE_LANDING_V2=false` in the deployment environment.
2. Redeploy.

The v1 landing page (globe hero, service drawer, decision tree) is preserved and will be served instead.

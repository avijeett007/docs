## Your first sign-in

After signing in for the first time, finish any security or account setup prompts shown by the portal. Once those dialogs are closed, the dashboard can introduce the main controls you will use.

The introduction runs once. If another dialog interrupts it, close that dialog and continue from the same step.

## Start from the dashboard

The dashboard gives you a guided path through the first account tasks. Depending on your plan and progress, it may point you to:

- finish your portal branding and domain setup
- add your first customer
- create an AI agent
- assign a phone number
- connect payments and choose customer plans

Your progress is saved as you complete the actions shown in the portal.

## Find more features

The sidebar focuses on the areas available to your account. Select **Browse all options** to see other available areas. Some options appear only after the related service or account level is enabled.

<Tip>
Use the labels and progress shown in your portal as the current source of truth because the available setup steps can differ by account.
</Tip>

## If setup is interrupted

- Close the open dialog and return to the dashboard.
- Refresh the page if the dashboard remains in a loading state.
- If the introduction has already finished, use the dashboard checklist and sidebar to continue setup.
- Select **Get Support** if your progress does not update after retrying.

## Who this documentation is for

These docs are written for partners and agencies who manage one or more customers on Knotie AI Pro.

## What you'll learn

- How to create and secure your account
- How to onboard customers and configure their portal access
- How to set up whitelabel and custom domains
- How to work with agents (Retell and VAPI)
- How to use partner-facing APIs (MCP)

## Portal types

- Customer portal: used by your customers.
- Whitelabel portal: used by partners/agencies to support customers and manage portal settings.

## Live partner count

The Knotie AI Pro landing page displays a real-time count of active partners using the platform. Two places show this figure:

- **Hero eyebrow** — "Knotie AI Pro · X+ partners selling"
- **Trust bar** — "X+ partners onboarded"

Both numbers are pulled from the `/api/public/live-stats` endpoint via the page-level `LiveStatsProvider`. The initial value is rendered server-side (SSR), so the count shown on first load is accurate — not a placeholder. The figure then refreshes every **3 minutes** in the background.

Because the counter reflects the actual, current partner base, you can quote it with confidence when presenting the platform to prospects.

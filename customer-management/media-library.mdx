## What the media library is for

The **Docs & Media** section has two tabs:

- **Media** — images and videos stored on a public URL. Files get a stable link with no expiry, so agents, social posts, and widget templates can reference them directly.
- **Docs** — private documents (PDFs, Word, spreadsheets, and more) stored securely on Cloudflare R2. Access requires a time-limited signed download link.

Use the media library when a customer wants to:

- Store brand images, logos, or product photos for agents to use in social posts (Media tab)
- Upload private PDFs, reports, or reference documents for agents to retrieve (Docs tab)
- Build a reusable asset bank for marketing or outreach campaigns (Media tab)
- Let an AI agent save call summaries or notes as documents (Docs tab)

## Prerequisites

Before a customer can see the Docs & Media section in their portal:

1. The partner must enable the **Docs & Media** menu toggle in that customer's **Features & Add-ons** panel.
2. The customer must have an active portal account.

See [Features, add-ons, and menu visibility](/partner-portal/customers/features-addons-and-menu-visibility) for the toggle location.

## Storage quotas per plan

Storage is now enforced per-plan. Each partner account has a pool limit, and each customer gets an individual cap configured by the partner.

| Plan | Partner pool |
|---|---|
| Free Forever | 100 MB |
| Solo Agency / Pro | 1 GB |
| Ultimate Scaleup Agency | 5 GB |

When a customer hits their individual cap, uploads return an error instead of consuming partner storage. When the partner pool is full, uploads across all customers are blocked until storage is freed.

Partners can adjust a customer's individual cap in **Customers → Manage → Features & Add-ons → Allocated Storage (MB)**.

## Uploading media assets (Media tab)

1. Open the customer portal and navigate to **Docs & Media → Media**.
2. Select **Upload** and choose an image or video file.
3. The platform checks the file against the customer's allocated storage cap.
4. On success, the file appears in the card grid with its name and a stable public URL.

Accepted types: images (PNG, JPG, WEBP, GIF) and video files. For documents (PDF, DOCX, and others), use the Docs tab.

## Uploading documents (Docs tab)

Documents are stored privately. See [Documents and folders](/customer-management/documents-and-folders) for the full guide, including folder creation, downloads, and moving files.

## Searching and managing assets

- Use the **search bar** to filter assets by name within the current tab.
- Each card shows a preview (for images), the file name, and action buttons.
- Select **Delete** on a card to permanently remove the file from storage.
- Media cards also offer **Move to…** to place the asset in a folder in the Media tab.

Deletions are immediate and cannot be undone. Storage is reclaimed after deletion.

## Using media assets in agents

Media asset URLs are stable and do not expire. Paste a URL directly into an agent prompt, a social post template, or any field that accepts a URL.

Agents granted the `MEDIA_LIST_ASSETS` MCP tool can retrieve a customer's asset list programmatically, and agents with `MEDIA_IMPORT_FROM_URL` can pull external images directly into the media library.

For documents, agents use `MEDIA_GET_DOWNLOAD_URL` to obtain a signed link and `MEDIA_SAVE_TEXT` to store notes or summaries as files.

See [MCP media tools](/api-reference/mcp/media-tools) for a full reference.

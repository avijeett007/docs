## Overview

Select **Connect to my agents** from Media Studio to create a media-only connection for a compatible agent or automation tool.

![Media Studio agent connection with production limits and optional skills](/images/screenshots/media-studio-agent-connection-production-2026-09-14.png)

## Create a connection

1. Open **Media Studio**.
2. Select **Connect to my agents**.
3. Choose the creation limit that fits the work: everyday, one short film, or a full production.
4. Select **Generate connection**.
5. Follow the setup shown for your agent or automation tool.

The connection is limited to Media Studio creation and gallery actions. The agent quotes a job before it uses credits, and a refused job is not charged.

## Optional setup files

The panel also offers downloadable skills and commands that teach compatible agents the Media Studio workflow. These files explain the workflow; the connection itself grants access.

<Warning>
Treat connection details like a password. Revoke a connection from your Studio tokens if it is no longer needed or may have been exposed.
</Warning>

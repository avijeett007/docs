## Overview

Storyboard is an **Experimental** Media Studio workspace for planning and producing a multi-scene film. A board belongs to one project so its cast, images, and final cut stay together.

![Media Studio Storyboard asking the user to choose or create a project](/images/screenshots/media-studio-storyboard-production-2026-09-14.png)

## Start a board

1. Open **Media Studio → Storyboard**.
2. Choose the project for the film, or select **New project**.
3. Continue with the planning options shown for that project.
4. Review any credit quote before starting a generation.

<Warning>
Storyboard is an early preview. Its layout and available actions may change.
</Warning>

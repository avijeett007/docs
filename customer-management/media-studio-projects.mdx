## Overview

A project keeps the assets for one campaign, customer, or production together. Your credits, Library, and Characters remain shared across projects.

## Create and use a project

1. Open **Media Studio → Projects**.
2. Select **New** and name the project.
3. Return to Home or Recipes.
4. Use **Filing into** to select the project before you create.

Everything created while that project is selected is filed into it. Choose **No project** when the result does not belong to a project.

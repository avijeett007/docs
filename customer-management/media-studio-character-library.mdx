## Overview

The Character Library gives Motion Studio access to 32 ready-made stylised characters across four art styles — **Clay**, **Papercraft**, **Comic**, and **Hand-drawn**. When you create a video that uses a character slot, Motion Studio can either pick the best-fitting library character for your brand and message, or create a new original character using the same style as a reference.

## How it works

When you submit a brief for a video that includes a character slot, Motion Studio follows these steps:

1. Checks the library for a character that fits the template style and your brief's industry, mood, and message.
2. If a matching character exists, it offers that character — along with its model sheet as a reference — to keep the figure on-model.
3. If no match is found, it generates a brand-new character in the same style using library sheets as visual references, and adds it to your video.
4. The AI applies **close-up framing** to position the character's face inside the safe area of the template, so the face is never obscured by borders, captions, or frame edges.

<Note>
Library characters are shared assets (licence L10). A character created specifically for your brand is kept private to that job (licence L11) and is never added to the shared library.
</Note>

## Character styles

| Style | What it looks like | Typical use |
|---|---|---|
| **Clay** | Soft, moulded 3-D figures with smooth shapes | Friendly, approachable brands |
| **Papercraft** | Layered cut-paper look with visible texture | Creative studios, education |
| **Comic** | Bold lines, flat colour, expressive faces | Entertainment, Gen-Z brands |
| **Hand-drawn** | Loose pencil or brush strokes with warmth | Personal brands, artisan, lifestyle |

## Close-up framing

When a video cuts to a close-up of a character, Motion Studio automatically adjusts the zoom and position so the character's face lands within the template's safe area — clear of borders, captions, and the frame edge. No manual cropping is needed.

## Frequently asked questions

**Can I upload my own character?**
Not yet. The Character Library currently provides 32 pre-built characters. Custom character upload is planned for a future release.

**Will the same character appear in every video?**
Only if it is the best match for each brief. Motion Studio picks the character that suits your brand's sector, mood, and selected template. Different briefs may produce different character selections.

**What happens if no character fits my brief?**
Motion Studio creates a new character in the matching style, using library sheets as references. The new character's appearance is checked by AI before the still is used.

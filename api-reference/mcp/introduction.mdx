## What are MCP APIs?

MCP APIs are partner-facing endpoints that help you automate common operations, including:

- Customer onboarding
- Portal access enable/reset/block
- Agent mapping for Retell and VAPI
- Team member management

## Who should use this

Partners and agencies who want to integrate Knotie AI with internal systems or workflows.

<Warning>
This feature is currently **not available** in the live Partner Portal UI. The Knowledge Base Processing Configuration section does not appear on the Settings page, and direct URLs return 404.

Until this feature ships, knowledge base functionality is managed per-customer under **Features & Add-ons** → **Add-on Features**.
</Warning>

<Info>
  **KB v2 is now live.** The settings on this page apply to the legacy AnythingLLM processing path. For the new tier-driven KB v2 credit model, see [Knowledge Base v2](/partner-portal/knowledge-base-v2).
</Info>

## What this setting controls (when available)

The **Knowledge Base Processing Configuration** section is intended to let partners configure the credit cost of knowledge base processing.

This would be useful if you:

- Want predictable margins
- Need to enforce file size limits
- Want to charge overage costs for large files

## Where to find it (when available)

1. Open **Settings**.
2. Scroll to **Knowledge Base Processing Configuration**.

## Planned controls

When shipped, the UI may include controls for:

- **Base Processing Cost (Credits)**
- **Included File Size Limit (MB)**
- **Overage Cost per MB (Credits)**

## Current alternative

For now, enable knowledge base access per customer:

1. Partner Portal → **Customers**
2. Click **Manage** on a customer
3. Go to **Features & Add-ons**
4. In **Add-on Features**, check for knowledge base related toggles
5. In **Menu Visibility Options**, ensure **Knowledge Base** is visible

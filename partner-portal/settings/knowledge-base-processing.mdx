## What this setting controls

The **Knowledge Base Processing Configuration** section lets you configure the credit cost of knowledge base processing.

This is useful if you:

- Want predictable margins
- Need to enforce file size limits
- Want to charge overage costs for large files

## Where to find it

1. Open **Settings**.
2. Scroll to **Knowledge Base Processing Configuration**.

## What you can configure

The UI includes controls for:

- **Base Processing Cost (Credits)**
- **Included File Size Limit (MB)**
- **Overage Cost per MB (Credits)**

It also shows your **Current Credit Balance**.

## Save and reset

- Click **Save** to apply changes.
- Use **Reset to Defaults** if you want to revert.
- Use the refresh icon to reload current configuration.

## Example cost calculation

If a file is larger than your included limit, the portal adds:

- Base cost + (overage MB \* overage cost)

Your main custom domain opens your customer portal. **Additional custom domains** let you add up to three more domains and send each one to a specific One-Click Experience. For example, `receptionist.youragency.com` could open your AI Receptionist experience directly.

![The Additional Custom Domains block in Domain Settings, with the Add domain button](/images/screenshots/additional-custom-domains-2026-09-29.png)

## Before you start

- Your main custom domain must already be set up and verified. See [Custom domain](/customer-management/custom-domain).
- The experience you want to use must be turned on in **One-Click Experiences**.
- If your plan doesn't include this feature, you'll see an upgrade notice in this section instead.

## Add a domain

1. Open **Settings → White-Label Portal**.
2. Expand **Domain Settings**.
3. Under **Additional Custom Domains**, select **Add domain**.
4. Type the domain, for example `portal.yourbrand.com`, and select **Add**.

The domain appears in the list with the DNS record you need to add.

## Verify the domain

1. Sign in to the company where you manage your domain's DNS.
2. Add the record shown in the portal.
3. Wait for the change to take effect. This usually takes a few minutes but can take a few hours.
4. Return to the portal and select **Verify** next to the domain.

Once the check passes, the domain is marked **Verified**. Only verified domains can be linked to an experience.

## Link the domain to an experience

1. Open **One-Click Experiences**.
2. On the experience you want, select **Make default**.
3. If you have more than one domain, choose which domain should open this experience, then confirm.

The change takes effect straight away. The experience card shows which domain it's linked to.

To move a domain to a different experience, free it from its current experience first, then link it to the new one.

## What visitors see

| Situation | What visitors see |
|---|---|
| Domain linked to an active experience | That experience |
| Domain not linked yet, or linked to a turned-off experience | A "not set up yet" notice |

Your main custom domain and your Knotie subdomain always open your portal's default experience.

## Remove a domain

Select the delete icon next to the domain and confirm. Anyone using that domain will no longer reach your experience, so check that it isn't in use in links or marketing first. You can add the same domain again later.

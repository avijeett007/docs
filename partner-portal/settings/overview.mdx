## What Partner Settings is

The **Settings** page in the Partner Portal is where you configure the infrastructure behind your agency account:

- Billing setup (your subscription)
- Integrations (provider API keys)
- Email sending (SMTP or Domain Email Service)
- Security (password, MFA, passkeys)
- Stripe Connect (to collect payments)
- Branding (portal title, slogan, logo, colors)
- Knowledge base processing costs

## Where to find it

In the Partner Portal sidebar, open **Settings**.

## How Settings is organized

The Settings page is organized into sections such as:

- **Subscription & Billing**
- **Integration Settings**
- **Security Settings**
- **Passkey Authentication**
- **Email Settings**
- **Stripe Connect**
- **Whitelabel settings**
- **Knowledge Base Processing Configuration**

Use the pages in this section to configure each area safely.

## Recommended order

If you’re setting up a new partner account:

1. Configure **Integrations** (provider API keys).
2. Enable **Security** (MFA + passkeys).
3. Set up **Email** (SMTP _or_ Domain Email Service).
4. Configure **Stripe Connect** if you plan to charge customers.
5. Review **Branding** for your customer portal.

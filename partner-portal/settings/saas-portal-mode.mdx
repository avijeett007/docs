## What SaaS Portal Mode is for

**SaaS Portal Mode** transforms your whitelabel portal into an enterprise-grade funnel experience with:

- Automated prospect onboarding
- Self-service customer signup
- Built-in AI Receptionist landing pages
- Free trial capabilities
- Advanced conversion tracking

This mode is ideal for agencies running a "productized" SaaS offering instead of traditional done-for-you services.

## Portal modes explained

Knotie AI Pro offers three portal modes:

### Basic Mode (Default)
- Traditional customer management portal
- Manual customer onboarding
- Simple, straightforward interface
- Available on all plans

### Professional Mode
- Enhanced portal with premium branding
- Advanced customization options
- Professional theme templates
- Available on Starter and above

### SaaS Mode (Enterprise)
- Full funnel automation
- Self-service signup flows
- AI Receptionist landing pages
- Prospect management system
- Available on Starter, Pro, Enterprise, Ultimate tiers

## Prerequisites

To use SaaS Portal Mode, you need:

1. **Paid plan** – Starter, Pro, Enterprise, or Ultimate tier
2. **Whitelabel portal configured** – Subdomain or custom domain set up
3. **Stripe Connect** – For processing customer payments (optional but recommended)
4. **Manual enablement** – Special offers may provide SaaS mode access on lower tiers

## Enable SaaS Portal Mode

### Step 1: Select SaaS mode

1. Go to **Settings → Whitelabel**.
2. Find the **Portal Mode** section.
3. Click on **SaaS Portal**.
4. If you don't have access, you'll see an upgrade prompt.

### Step 2: Configure SaaS settings

Once SaaS mode is selected, the **SaaS Portal Configuration** section appears:

1. **Character Name** (Optional)
   - Add a character name for personalized branding (e.g., "Sarah", "Alex")
   - If left empty, uses your business name
   - This appears in the AI Receptionist onboarding flow

2. **Free Trial Enabled**
   - Toggle ON to show "Start Free Trial" button on landing page
   - Allows prospects to try before buying
   - Default: Enabled

3. **SaaS Onboarding Enabled**
   - Toggle ON to enable the 9-step onboarding flow
   - Prospects fill out business info, connect knowledge base, etc.
   - Auto-deploys AI agent when complete

4. **Free AI Credits**
   - Set initial credits for new signups (e.g., 50, 100, 500)
   - Helps prospects test without payment
   - Default: 50 credits

5. **Pricing Model**
   - **Subscription** – Monthly/annual plans
   - **Pay-as-you-go** – Usage-based billing
   - **Fixed Price** – One-time setup fee

6. **Pay-as-you-go Rate**
   - Set rate per minute if using pay-as-you-go model
   - Example: $0.10 per minute
   - Only applies if pricing model is "Pay-as-you-go"

![SaaS Portal Configuration Panel](/images/screenshots/Screenshot%202026-03-19%20221234.png)

### Step 3: Configure agent tier

Choose which AI agent tier prospects get:

- **Essentials** – Basic AI capabilities
- **Professional** – Enhanced features
- **Enterprise** – Full capabilities

This determines what's available to customers who sign up through your SaaS portal.

### Step 4: Save configuration

1. Scroll to the bottom.
2. Click **Save Settings**.
3. SaaS mode is now active on your whitelabel portal.

### 9-step onboarding flow

> The 9-step onboarding flow is available **only in SaaS portal mode**.

Prospects who click "Start Free Trial" go through a guided onboarding:

1. **Business Info** – Company name, website
2. **Website Verification** – Validate business website
3. **Contact Details** – Email, phone
4. **Service Categories** – What the business offers
5. **Knowledge Base** – Upload FAQs, documents
6. **Greeting Setup** – Configure AI greeting message
7. **Information Collection** – What data to collect from callers
8. **Communication Settings** – Email/SMS preferences
9. **Summary & Deploy** – Review and activate

**At Step 3:** Prospect converts to Customer (moves from Prospects tab to Customers tab)

**At Step 9:** AI Agent auto-deploys and is ready to handle calls

## Auto-deploy configuration

When SaaS onboarding is enabled, auto-deploy activates AI agents automatically:

### How auto-deploy works

1. **Prospect completes Step 9** – All onboarding steps finished
2. **System validates** – Checks for credits, phone number, agent configuration
3. **Agent deployed** – AI Receptionist is activated
4. **Customer notified** – Email confirmation sent (if configured)
5. **Ready for calls** – Agent starts handling calls immediately

### Auto-deploy requirements

For auto-deploy to work, ensure:
- **Free AI Credits configured** – Customers need credits to use the agent
- **Default agent selected** – Set which agent template to deploy
- **Phone number assignment** – Configure number provisioning (optional)

## Pricing model configuration

### Subscription pricing

For subscription-based SaaS:

1. Set **Pricing Model** to "Subscription".
2. Configure subscription plans in **Subscription Plans** section.
3. Add monthly/annual tiers (Basic, Pro, Enterprise).
4. Enable Stripe for recurring billing.

### Pay-as-you-go pricing

For usage-based billing:

1. Set **Pricing Model** to "Pay-as-you-go".
2. Set **Pay-as-you-go Rate** (e.g., $0.10 per minute).
3. Customers are charged based on actual usage.
4. Requires AI Credits system enabled.

### Fixed price

For one-time setup fees:

1. Set **Pricing Model** to "Fixed Price".
2. Configure one-time pricing in your billing settings.
3. Customers pay upfront for setup.

## Troubleshooting

### SaaS mode not available
- **Upgrade required** – You're on Free Forever plan, upgrade to Starter or above
- **Contact support** – Request manual SaaS mode enablement

### Landing page not showing
- **Portal mode not saved** – Verify SaaS mode is selected and saved
- **DNS not configured** – Check custom domain is verified
- **Cache issue** – Clear browser cache and try in incognito mode

### Onboarding flow not working
- **SaaS Onboarding disabled** – Toggle "SaaS Onboarding Enabled" to ON
- **Missing configuration** – Ensure all SaaS settings are filled in
- **Free credits not set** – Configure Free AI Credits amount

### Auto-deploy failing
- **Insufficient credits** – Increase Free AI Credits allocation
- **No agent selected** – Configure default agent template
- **Integration missing** – Check provider API keys are configured

## Best practices

- **Test the full funnel** – Go through onboarding as a prospect before going live
- **Set appropriate free credits** – Enough to test but not too much to abuse
- **Monitor drop-off points** – Improve steps where prospects abandon
- **A/B test pricing** – Try different models and rates
- **Provide clear value propositions** – Explain benefits on landing page
- **Optimize for mobile** – Many prospects will sign up on mobile devices

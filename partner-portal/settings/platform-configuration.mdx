## What Platform Configuration is

The **Platform Configuration** card in Partner Settings gives you two controls in one place:

1. **Dashboard Mode selector** — picks the overall layout and feature set your customers' portal uses.
2. **Default menu customizer** — controls exactly which sidebar menu items new customers have toggled on when they are created.

New customers are automatically seeded with your per-mode defaults the moment they are onboarded, so every customer starts with the right menu from their very first login — no per-customer manual toggling required.

The per-experience **Dashboard Experience** picker, which changes the look of the dashboard rather than its menus, is covered in [Per-Experience Customer Dashboards](/partner-portal/experiences/experience-dashboards).

## Dashboard Modes

Knotie AI Pro supports five dashboard modes. Four can be selected today; JARVIS is coming later.

![Platform Configuration with the Standard, Agency + Infra, Infrastructure, Integrations & Approvals, and JARVIS (Upcoming) mode cards](/images/screenshots/platform-configuration-modes-2026-09-29.png)

| Mode | Description | Best for |
|------|-------------|----------|
| **Standard** | Voice agents and the tools around them — the default. | Partners that resell AI voice and chat agents. |
| **Agency + Infra** | Everything, plus the infrastructure dashboard. | Partners reselling both AI agents and servers. |
| **Infrastructure** | Servers and hosting only. | Partners whose main offering is servers and hosting. |
| **Integrations & Approvals** | Connected apps, MCP access, and phone approvals. | Partners who sell connected apps rather than voice agents. |
| **JARVIS** ⚡ _Upcoming_ | Autonomous operations (not yet available). | A future tier. |

Only one mode is active at a time. JARVIS is shown but can't be selected yet.

### Integrations & Approvals mode

Choose this mode if your customers buy connected apps rather than voice agents. Their portal is built around:

- **Integration** — connecting apps such as Gmail, Slack, and HubSpot
- **MCP Access** — connecting AI assistants and automations to those apps
- **Approvals** — approving risky agent actions from their phone. See [Phone approvals for agent actions](/agents/phone-approvals).

Voice-agent menus such as AI Agents, Knowledge Base, and Phone Numbers are hidden from the menu in this mode.

Customers still need **Integration** turned on to use the Integration page. If you also want to stop customers opening voice-agent pages directly, turn those features off in each customer's [Features & Add-ons](/partner-portal/customers/features-addons-and-menu-visibility).

To match the look of the dashboard, you can also choose the **Integrations & Approvals** style under **Dashboard Experience → Default dashboard**.

## How to set a Dashboard Mode

1. In the Partner Portal sidebar, open **Settings**.
2. Scroll to **Platform Configuration**.
3. Click the mode card you want — **Standard**, **Agency + Infra**, **Infrastructure**, or **Integrations & Approvals**.
   - The selected card shows a check-mark (✓) and a blue border.
   - The change is saved immediately when you click.
5. The **Default menu** grid below updates automatically to show the features available for the new mode.

## Customizing default menus

Below the mode cards is the **Default menu for new customers** grid. Each item is a sidebar menu entry (or capability flag) that will be toggled on or off for every new customer created under the active mode.

<Warning>
These defaults apply only to **new** customers created after you save. Existing customers keep their individual settings. To change an existing customer's menu, see [Features, Add-ons & Menu Visibility](/partner-portal/customers/features-addons-and-menu-visibility).
</Warning>

### Feature groups

The grid has three groups:

| Group | Contents |
|--------|----------|
| **Standard** | Voice agents and the tools around them. Hidden in Infrastructure mode. |
| **Integrations & Approvals** | Integration, and MCP Access & Approvals. |
| **Infrastructure** | Servers, AI Gateway, AI Memory, and Media Studio. |

### Infrastructure features

| Feature | What it gives customers | Partner switch required |
|---------|------------------------|-----------------------|
| VPS Marketplace | Buy and manage servers (My Servers, AI Chat). | — |
| Connect Your Server | Connect their own server through the terminal. | — |
| AI Gateway | Create AI Gateway keys. | AI Gateway |
| AI Memory (My Minds) | Long-term memory for customers and agents. | AI Memory |

### Partner-gated features

**AI Gateway** and **AI Memory** require a partner-level master switch to be on first. If the switch is off, the toggle shows a lock icon (🔒) and cannot be changed:

- **AI Gateway** → enable _AI Gateway_ in your partner account settings first.
- **AI Memory** → enable _AI Memory / My Minds_ in your partner account settings first.

### Feature dependencies

**API Keys** requires **API Access** to be on — enabling API Keys without API Access has no effect. The UI enforces this automatically: the API Keys toggle is grayed out until API Access is enabled.

### Saving your defaults

After toggling features, click **Save defaults** to persist the profile for the active mode. The button is disabled (grayed out) when there are no unsaved changes.

![Default menu for new customers in Standard mode, with the Standard group on the left, the Infrastructure group on the right, and the Save defaults button](/images/screenshots/platform-configuration-default-menu-2026-09-29.png)

You can configure a separate profile for each mode independently (e.g., a minimal menu for Standard customers and a fuller one for Agency + Infra customers). Switch between mode cards to edit each profile.

## How new customers inherit these defaults

When you create a new customer — via **Quick Onboard**, the **Add Customer** modal, or the experience-booking signup flow — the platform resolves the customer's starting feature set in this order:

1. **Catalog baseline** — each feature has a built-in default (most features default **off**; Pricing Information defaults **on**).
2. → **Your per-mode profile** — your saved Platform Configuration settings for the active mode override the baseline.
3. → **Subscription plan overrides** — the customer's plan may enable or lock features.
4. → **Experience-level overrides** — e.g., signing up via the AI Gateway experience enables AI Gateway regardless of the mode profile.

The result is applied to the new customer's portal at creation time. The customer's sidebar reflects these settings from their first login.

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Will changing the mode affect existing customers?">
    No. Switching the active Dashboard Mode or saving a new default profile only affects **new** customers created after the save. Existing customers retain their individual feature settings.
  </Accordion>
  <Accordion title="Can I turn off a feature for all existing customers at once?">
    Platform Configuration only sets defaults for new customers. To turn some features on for everyone, use **Apply to Existing Customers** under **Customer Portal Defaults** on the same Settings page — it covers AI Gateway, VPS Purchase, Integration, and MCP Access & Approvals. These bulk actions can't be undone automatically. For anything else, change each customer in [Features, Add-ons & Menu Visibility](/partner-portal/customers/features-addons-and-menu-visibility).
  </Accordion>
  <Accordion title="What happens if I have no saved profile for a mode?">
    New customers fall back to the built-in defaults — most features off, with Pricing Information on. Any older AI Gateway or VPS settings on your account are still honored, so nothing breaks if you haven't saved a profile yet.
  </Accordion>
  <Accordion title="JARVIS says 'Upcoming' — when will it be available?">
    JARVIS is a future autonomous-operations tier currently in design. There is no ETA yet. The card is shown so you can see where it fits in the mode lineup.
  </Accordion>
</AccordionGroup>

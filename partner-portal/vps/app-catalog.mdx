## Open the app controls

Go to **VPS Settings** and scroll to **One-Click Apps**.

The master switch controls whether customers see ready-made apps on their server pages. The production catalog is searchable and groups apps by category.

![One-Click Apps settings with search, categories, and customer visibility controls](/images/screenshots/vps-one-click-apps-production-2026-09-14.png)

## Choose visible apps

The Featured set is shown by default. Select individual cards to build a custom list; cards are labelled **Visible** or **Hidden**.

The current Featured set includes OpenClaw, Hermes Agent, and Buzz Relay. The wider catalog includes monitoring, productivity, finance, AI, media, automation, security, publishing, and developer tools.

<Note>
Catalog contents change over time. Use search or the category headings in the portal to confirm what is currently available.
</Note>

## Set access for one customer

1. Open **Customers → Active Customers**.
2. Select **Manage → Features & Add-ons**.
3. Find **One-Click Apps on Servers**.
4. Choose **Inherit**, **Show**, or **Hide**.
5. Save.

**Inherit** follows the global VPS setting. A customer-specific choice overrides it for that customer.

## Create an app package

Use **App Packages** in VPS Settings to combine apps with a server plan and offer them as one package.

1. Select **New Package**.
2. Add the package name and description.
3. Choose the apps and server plan.
4. Set the monthly or yearly customer price shown in the form.
5. Publish the package when it is ready.

Review package pricing and app access before sharing it with customers.

## Reinstall an active server

Use **Reinstall** from the instance card when you need a fresh operating system or a different One-Click App.

<Warning>
Reinstall is destructive and wipes existing server data.
</Warning>

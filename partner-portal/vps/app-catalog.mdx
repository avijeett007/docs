## What you can do

The **VPS** section of the Partner Portal lets you:

1. **Purchase VPS servers** for your customers (6 plan tiers, $6.98–$75.57/mo)
2. **Browse the full App Catalog** — ~94 platform-enabled apps, searchable with per-app install badges
3. **Deploy apps to active servers** without reinstalling — add a second or third app to a running server
4. **Create App Packages** — bundle apps with a VPS plan; catalog-only apps auto-deploy when the server goes active
5. **Control visibility** — choose which plans and apps your customers can see

## App Catalog page

The **App Catalog** is a dedicated sidebar entry (under **INFRASTRUCTURE → App Catalog**) that shows every platform-enabled app in one searchable view — not just the three that were previously curated.

### Finding apps

- Use the **search bar** at the top to filter by name, tag, or description.
- Each app card shows its logo, name, category tags, and live install counts across your servers.
- Click any app card to open its detail overlay (description, features, RAM estimate, access port, website, GitHub link).

### Install badges

Each card shows real-time deployment state across all your customers' servers:

| Badge | Meaning |
|-------|---------|
| **Installed on N servers** | App is fully installed and running on N of your servers |
| **Installing on X** | Active deployment in progress on X servers |
| _(no badge)_ | Not deployed anywhere yet |

## Deploying apps to an active server

You no longer need to reinstall a server to add a new app. From the **App Catalog**, you can deploy any app to a server that is already active:

1. Open the **App Catalog** from the sidebar.
2. Click an app card to open the detail overlay.
3. Click **Deploy to a server**.
4. Select the target server from the list of eligible active instances.
5. Fill in the app's setup form (credentials, port config, or other inputs the app requires).
6. Click **Deploy**.

### Tracking multi-app installs

The **My Servers** view (VPS Servers → My Instances) shows each server's installed apps inline. Each installed app has its own status:

| App status | Meaning |
|-----------|---------|
| Queued | Scheduled, waiting for the server to become ready |
| Deploying | Currently installing |
| Installed | Running and accessible |
| Needs setup | Deployed but requires configuration input from the customer |
| Failed | Last deploy attempt errored — error message shown |

If an app shows **Needs setup**, the customer sees a "Finish setup" prompt in their portal.

## Reinstalling a server

To replace a server's entire software stack (wipes all data):

1. Open **My Servers** (VPS Servers → My Instances).
2. Click **Reinstall** on an active instance.
3. Select a new app or package from the reinstall modal.
4. Check the confirmation box: _"I understand this will permanently delete all data on this server and reinstall the OS."_
5. Click **Reinstall VPS**.

The reinstall modal still has **Single App** and **Build Package** modes for full-stack replacements.

## App Packages (VPS Settings)

> **Where to find App Packages:** Open **VPS Servers** in the sidebar, then click **VPS Settings**. Scroll to **App Packages** at the bottom.

Create pre-configured bundles that pair a VPS plan with a set of apps and a customer-facing price.

### Create a package

1. Click **New Package** — a sidebar slides in from the right.
2. Enter a **package name** — e.g. "AI Starter Stack", "Automation Pro".
3. Choose a **base VPS plan** (e.g. Cloud VPS 10, 20, 30…).
4. Select which **apps** to include.
5. Set your **monthly/yearly price** shown to customers in their whitelabel portal.
6. Toggle **visibility** per plan tier.
7. Click **Save**.

### Package auto-deploy on provisioning

When a customer purchases a package, the platform handles app deployment automatically based on the app type:

- **One-click apps** (apps that install with no user input, e.g. OpenClaw): deploy automatically via cloud-init as the server provisions. The server arrives fully configured.
- **Input-required apps** (apps that need credentials or port config): recorded at purchase and surfaced to the customer as **Finish setup** prompts in their portal as soon as the server is active.

OpenClaw is automatically provisioned with a Knotie API key for each customer — no manual setup required.

## VPS Settings

| Setting | What it does |
|---------|-------------|
| **Enable VPS for Customers** | Toggle on/off — lets customers purchase VPS from their whitelabel portal |
| **Customer Margin (%)** | Markup on your partner cost. Example: Cloud VPS 10 costs you $6.98/mo. At 20% margin, customers see $8.38/mo. Can be overridden per customer. |
| **Display Currency** | Currency shown to customers (USD, GBP, EUR, AUD, CAD, SGD, INR). Your billing from Knotie is always in USD. |
| **Plan Visibility** | Choose which server plans customers can see. All 6 shown by default. |

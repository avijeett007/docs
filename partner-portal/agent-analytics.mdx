## What Agent Analytics is for

**Agent Analytics** helps you understand what’s happening across your AI agents:

- Total calls
- Total call duration
- Average duration
- Success rate
- Cost breakdown (LLM, STT, TTS, and provider costs)

This is the page you use to:

- Price services correctly
- Check profit margins
- Spot sudden spikes
- Diagnose failed calls

## Where to find it

In the Partner Portal sidebar, open **Agent Analytics**.

## Before you start (most common blockers)

If you see a message like “Please update your API keys & onboard Agents first,” it usually means:

- You haven’t added provider API keys yet, or
- You haven’t imported/created agents yet.

Fix:

1. Go to **Settings → Partner API Keys → Platform API** tab. Create or update your `pkt_` keys here.
   - The live Settings sidebar has 5 items: Profile Settings / **Partner API Keys** / Email Domain Management / Plans & Billing / White-Label Portal. There is no top-level "Settings" entry.
   - The Partner API Keys page has 4 tabs: AI Gateway Beta / Platform API / MCP Tokens / n8n Tokens. Platform API is where partner-automation keys (`pkt_`) live. AI Gateway Beta tab holds `sk_` LLM-billing keys.
2. Return to **AI Agents** (sidebar button under AI PLATFORM) and import/create agents.
3. Come back to **Agent Analytics**.

## Choose the time period

Agent Analytics supports time windows such as:

- **Day**
- **Week**
- **Month**

Use **Month** for pricing decisions and **Day** for troubleshooting spikes.

## What the cost breakdown means

You’ll often see costs split into parts like:

- **LLM**: the AI “brain” behind the conversation
- **STT**: speech-to-text (turns audio into text)
- **TTS**: text-to-speech (creates the voice)
- **Provider costs**: Retell / VAPI / Ultravox / GHL / ElevenLabs / Knova

If one category grows unusually fast, it’s a signal to review:

- Prompt length
- Call flow
- Agent configuration
- Provider settings

## Viewing individual agent analytics

While the main view shows **overall costs for all agents**, you can also load analytics for a specific agent:

1. Use the agent selector/filter at the top of the page.
2. Select the agent you want to analyze.
3. View detailed metrics for that specific agent.

This allows you to:
- **Identify top agents** – See which agents are handling the most calls.
- **Provider-based cost breakdowns** – Understand costs per provider (Retell, VAPI, Ultravox, etc.).
- **Troubleshoot specific agents** – Isolate issues to a single agent rather than your entire portfolio.

Metered billing is partially live as of the last walkthrough:

- **Stripe Connect** (the underlying billing rail) is live — partners can onboard their Stripe account today via **Settings → Partner API Keys** (see the [Metered billing setup guide](/partner-portal/metered-billing)). Confirmed: 2.5% platform fee, Express accounts.
- **The partner-portal metered-billing page** at `/partner/metered-billing` still shows a "Feature in Development" notice. Some sections (Billing Plans / Customer Billing) are not yet production-ready.

Until the partner-portal surface is fully released, use **Agent Analytics** to manually track usage and create invoices via **Billing & Invoices** (`/partner/billing`).

## Tips for agencies

- Review analytics weekly and adjust your markup if costs change.
- Use analytics screenshots in customer check-in calls (it builds trust).
- Load individual agent analytics to identify your most profitable agents.

## What MCP tokens are for

An **MCP token** lets an AI tool, such as Claude Desktop, Cursor, Windsurf, or n8n, use the apps a customer has connected in Knotie AI Pro. Each token belongs to one customer, and you decide which of that customer's apps and tools it can reach.

Use MCP tokens when you want to:

- **Let an AI assistant act for a customer**, for example reading their Gmail or updating their CRM.
- **Automate workflows** in tools like n8n.
- **Keep access narrow**, by giving each tool its own token limited to the apps it needs.

## Where to find it

Go to **AI Gateway → MCP Tokens** in the sidebar.

![The MCP Token Management page](/images/screenshots/mcp-tokens-page-2026-09-30.png)

The page shows the details you need to connect an AI tool:

- **Server URL:** `https://mcp.knotie-ai.pro/api/mcp`
- **Authentication:** Bearer token (the MCP token you create)
- **Cost:** each tool call uses 0.1 Knotie credits (about 1,000 calls = 100 credits ≈ $1)

## Create a token

1. On the **MCP Tokens** page, select **Create New Token**. The **MCP Token Manager** opens.
2. Open the **Create Token** tab.
3. Choose the **Customer** the token is for.
4. Enter a **Token Name** (for example, "Claude Desktop – Sales") and, if you like, a **Description**.
5. Choose the **Tool Scope** (see below).
6. Set the **Usage Limit (per hour)** and when the token **Expires In** (1 day to 1 year).
7. Select **Create Token**.
8. Copy the token straight away and store it somewhere safe, such as a password manager. It won't be shown again.

![The Create Token tab in the MCP Token Manager](/images/screenshots/mcp-create-token-modal-2026-09-30.png)

## Choose what a token can reach

**Tool Scope** becomes available once you've picked a customer. It has three options:

| Option | What the token can use |
|---|---|
| **All apps and tools** | Every app the customer has connected, including their mailbox if they have one connected. |
| **Specific apps** | Every tool of the apps you tick, and nothing else. |
| **Specific tools** | Only the individual tools you tick. Each app has a **Select All** shortcut. |

**Specific apps** is the easiest way to keep a token narrow. Each app shows how many tools it includes:

![Tool Scope set to Specific apps, with the Select Apps list](/images/screenshots/mcp-token-specific-apps-2026-09-30.png)

<Tip>
  If you don't want a token to touch a customer's email, choose **Specific apps** and leave their email apps (such as **Gmail** or **Email (any mailbox)**) unticked.
</Tip>

Creating tokens through the API? See [MCP tool modes](/api-reference/mcp/tool-modes) for the matching `apps` and mailbox options.

## Connect an AI tool

In your AI tool's MCP settings, add a server with:

1. The **Server URL** shown on the MCP Tokens page.
2. An `Authorization` header set to `Bearer` followed by your token.

Claude Desktop, Cursor, Windsurf, and n8n all support this. Look for "MCP servers" in their settings.

## Tool modes (full vs meta)

By default, a token gives the AI tool the complete list of tools at once (**full** mode). If you create tokens through the API, you can choose **meta** mode instead, where the tool searches for what it needs as it goes. Rate limits and credit charges are the same either way. See [MCP tool modes](/api-reference/mcp/tool-modes).

## Keep tokens safe

- **Never share tokens.** Treat them like passwords.
- **Use one token per tool**, so you can revoke one without affecting the others.
- **Keep scope narrow.** Only give a token the apps it needs.
- **Set an expiry** and replace tokens regularly.
- **Revoke tokens you no longer use.**

## Revoke a token

1. Go to **AI Gateway → MCP Tokens** and open the **MCP Token Manager**.
2. On the **Token List** tab, find the token.
3. Revoke or delete it, then confirm.

The token stops working immediately.

## Troubleshooting

- **Token not working:** check you copied the whole token with no extra spaces, and that it hasn't expired.
- **A tool is refused:** the token's **Tool Scope** may not include that app or tool. Create a new token with the right scope.
- **Tool Scope is greyed out:** choose a **Customer** first.

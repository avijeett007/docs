## Overview

Number Pools let you group phone numbers into reusable containers for campaign routing. Instead of assigning numbers one-by-one to campaigns, you create a pool and assign multiple numbers at once.

![Number Pool page with usage stats and empty-state pool list](/images/screenshots/number-pools-overview-2026-06-09.png)

The page header shows three stats — **Pool Usage**, **Total Pools**, and **Mapped Numbers** — followed by the pool list. With no pools created yet, an empty-state panel prompts you to create your first pool.

## Where to find it

1. Partner Portal → **Phone Numbers**
2. Click **Number Pool** (singular) in the page toolbar

## Pool usage stats

The top of the page shows:
- **Pool Usage** — X pools used (may show "unlimited plan" on higher tiers)
- **Total Pools** — number of pools created
- **Mapped Numbers** — total numbers assigned to pools

## Create a pool

1. Click **+ Create Number Pool**
2. Enter pool name (required) and a short description (optional)
3. Optionally assign the pool to a campaign (see [Campaign assignment](#campaign-assignment) below)
4. Search your phone number inventory and select numbers via checkboxes
5. Click **Create Pool**

![Create Number Pool modal — name, description, campaign assignment dropdown, and phone-number picker](/images/screenshots/number-pools-create-modal.png)

A number can only belong to **one pool at a time**. If you have no provisioned numbers yet, the picker shows "No phone numbers found" — go to **Phone Numbers** to buy or import a number first, then come back to create the pool.

## Manage a pool

Click **Manage Pool** on any pool card to:
- Edit name and description
- Add or remove numbers
- Change the assigned campaign
- Delete the pool

### Add or remove numbers

1. Open the Manage Pool modal
2. Numbers already in the pool are marked "Currently assigned" in green
3. Select additional numbers to add, or deselect to remove
4. Save changes

## Campaign assignment

You can assign a number pool to a **Campaign** so that all calls in that campaign use the numbers in the pool. The campaign rotates through the pool's numbers automatically for load-balancing and caller-ID variety.

### Assign a pool to a campaign when creating

1. Click **+ Create Number Pool**
2. Fill in name and description
3. In the **Campaign** dropdown, select the campaign you want to link this pool to
4. Add phone numbers
5. Click **Create Pool**

### Assign a pool to a campaign from the manage modal

1. Click **Manage Pool** on an existing pool
2. In the **Campaign** field, select or change the campaign
3. Save changes

### Remove a campaign assignment

1. Open **Manage Pool** for the pool
2. Clear the **Campaign** field
3. Save changes

The pool's numbers remain available in your inventory and can be reassigned to a different campaign or used individually.

## Delete a pool

In the Manage Pool modal:

1. Click **Delete Pool** (red button, bottom-left)
2. Confirm deletion

Numbers are released back to your available inventory.

## View pool details

Pool cards show:
- Name and description
- Creation date
- Assigned campaign (if any)
- Number count badge
- First 6 phone numbers as pills
- "+N more" if additional numbers exist

## Refresh

Click **Refresh** to reload all pools and your current plan limits.

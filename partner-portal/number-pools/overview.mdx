## Open Number Pools

Open **Phone Numbers** and select **Number Pool**. The page shows pool usage, total pools, mapped numbers, and the existing pool list.

![Number Pool overview with usage details and pool actions](/images/screenshots/number-pools-overview-2026-09-14.png)

## Create a pool

1. Select **Create Number Pool**.
2. Enter a name and optional description.
3. Select the phone numbers you want to group.
4. Choose a campaign if the form offers campaign assignment.
5. Create the pool.

If no numbers are available, return to **Phone Numbers** and buy or import a number first.

## Manage a pool

Select **Manage Pool** on a pool card. From the dialog, you can update the pool details and mapped numbers, change an available campaign assignment, or delete the pool.

Save your changes before closing the dialog.

## Use a pool with a campaign

When campaign assignment is available, choose the campaign while creating or managing the pool. Review the campaign before starting calls to confirm it uses the intended agent and pool.

To stop using the pool with that campaign, open **Manage Pool**, clear or change the campaign selection, and save.

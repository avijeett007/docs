## Where to find portal access actions

1. Open **Customers**.
2. Select a customer.
3. Open **Manage**.
4. Go to **Features & Add-ons**.
5. Find the **Customer Portal Access** area.

## Actions you can take

When the customer portal is enabled, the UI exposes buttons like:

- **Preview Portal**
- **Reset Password**
- **Block Access**
- **Delete**

## Preview Portal (secure impersonation)

**Preview Portal** opens a secure preview session in a new window.

Notes:

- The session is time-limited.
- If the popup is blocked, the UI will show an error like “Please check your popup blocker settings.”

## Reset Password

**Reset Password** is used to reset the customer’s portal password and send updated credentials.

Use this when:

- The customer lost access
- You suspect the account was shared

## Block Access

**Block Access** disables the customer’s ability to log in.

Use this when:

- A customer is overdue / suspended
- You need to stop access while you investigate security issues

## Delete portal access

**Delete** removes portal access.

Use this only when you are sure the customer should no longer have access.

## Common issue: Whitelabel setup required

If portal actions show an error mentioning whitelabel setup, the UI includes a **Fix Setup** shortcut that opens:

- `/partner/settings/whitelabel`

Complete whitelabel setup, then return to the customer modal.

## Where to find it

The **Tool Call Quota** tab only appears if **Integration** is enabled for the customer.

1. Open **Customers**.
2. Select a customer.
3. Open **Manage**.
4. Go to **Features & Add Ons**.
4. Enable **Integration**.
5. Open the **Tool Call Quota** tab.

## What happens when you enable Integration

When you enable Integration, the UI may display a notice:

- “Integration Enabled!”
- Basic tier quota example: **100 tool calls per 15 minutes**

## What you can do in Tool Call Quota

Depending on plan and configuration, you can:

- View current quota
- Upgrade quota tier
- Monitor usage

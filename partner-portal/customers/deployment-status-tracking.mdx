title: "Deployment status tracking"
description: "Track and update deployment progress per customer, including milestones like phone provisioned and agent ready for testing."
---

## Where to find it

1. Open **Customers** (sidebar — expands to Active Customers + Prospects).
2. Select a customer.
3. Open **Manage**.
4. Go to **Deployment**.

## Update deployment status

The Deployment tab contains a status selector with values like:

- Not Started
- Phone Number Provisioned
- AI Agent Deploying
- Agent Ready for Testing
- Deployment Complete

## Deployment notes

Use **Deployment Notes** to capture important context.

The UI saves notes when the field loses focus.

## Deployment timeline

The modal shows a timeline of milestones, such as:

- Deployment Requested
- Phone Number Provisioned
- Agent Deployment Started
- Agent Ready for Testing
- Deployment Completed

This is useful for internal tracking and for keeping customers informed.

## Where to find it

1. Open **Customers** (sidebar — expands to Active Customers + Prospects).
2. Select a customer.
3. Open **Manage**.
4. Go to **Features & Add-ons**.

## Customer Portal toggle

The first toggle is:

- **Enable Customer Portal**

This controls whether the customer can access their own portal.

If portal access cannot be enabled yet, the modal returns an eligibility error instead of silently turning the setting on.

## Add-on feature toggles

The modal currently includes these add-on controls:

- **Advanced AI Analytics**
- **Detailed Call Analysis**
- **Action Point Analysis**
- **API Access**
- **Knowledge Base Processing** - shown as **coming soon**

Notes:

- **Advanced AI Analytics** can be blocked at the partner level until the partner enables that capability first.
- **Knowledge Base Processing** is present in the UI but grayed out as coming soon.

## Website Studio

The customer modal now includes a **Website Studio** toggle.

- **Enable Website Studio** — lets this specific customer access Website Studio, the AI-powered website builder experience.

### How the access gate works

Enabling Website Studio for a customer requires two conditions to both be true:

1. **Partner master switch is on.** The partner must enable Website Studio at the platform level first (under **Experiences**). While the master switch is off, the toggle in the customer modal shows an amber badge as a reminder.
2. **Per-customer toggle is on.** Once the master switch is on, you can flip the per-customer toggle to grant that specific customer access.

If you try to access Website Studio with the per-customer toggle off, the experience returns a `403 — Website Studio is not enabled for your account` response.

<Info>
This mirrors the Media Studio access pattern. If you already manage Media Studio access per customer, Website Studio works the same way.
</Info>

## AI Credit Management

The AI credit section includes:

- **AI Credits Enabled**
- **Enable Notifications**
- **Low Credit Threshold**

When **AI Credits Enabled** is turned on:

- The customer is billed using AI Credits rather than standard dollar pricing.
- **Show Pricing Information** is automatically turned off.
- The **AI Gateway** menu becomes available to enable for that customer.

You can also turn on branded email alerts when the customer's credit balance runs low — set a threshold (in credits remaining) to trigger the alert.

If you turn **AI Credits Enabled** back off, the **AI Gateway** menu is also removed for that customer.

## Pricing information visibility

**Show Pricing Information** controls whether cost details appear in the customer portal. When **AI Credits Enabled** is on, this is automatically turned off — you can't run both at the same time.

## Menu Visibility Options

You can control which sections appear in the customer portal. The modal has 12 menu visibility toggles:

- Knowledge Base
- Integration
- Docs & Media (hidden by default — toggle on to show; see [Media Library](/customer-management/media-library))
- Social Planner (hidden by default — toggle on to show; requires Social Planner to be configured)
- Schedule Meeting
- Phone Numbers
- API Keys (requires API Access)
- AI Gateway Beta (requires AI Credits)
- Enable AI Memory (Mind) — **Beta**; gives the customer a persistent Mind their agents Remember, Recall, and Ask about across conversations (see [AI Memory](/partner-portal/ai-memory)). Turning it off only blocks access — the customer's existing Minds are **kept, not deleted**.
- MCP Access
- New Solutions
- Connect Your Server (VPS Access)

### API Keys visibility

**API Keys** can only be shown when **API Access** is enabled for that customer. If you turn off API Access, the API Keys menu is automatically hidden and its toggle is greyed out until you re-enable API Access.

### AI Gateway visibility

**AI Gateway Beta** is a separate toggle from API Keys. It becomes available only when **AI Credits Enabled** is turned on for the customer. When shown, it lets the customer generate their own AI Gateway API keys, billed through their AI Credits.

For the customer to see AI Gateway in their portal, you also need to enable **Customer Self-Service API Keys** on the partner-level [AI Gateway](/partner-portal/ai-gateway) page.

### Billing & Payments visibility

**Billing & Payments** appears automatically in the customer portal once the customer has active portal access — there's no manual toggle for it.

## Embed URLs and portal access

If you plan to generate customer-scoped embed links, first confirm the customer has portal access configured and the account is ready for embedded experiences.

Use [Embed URLs](/partner-portal/customers/embed-urls) when you need widget, iframe, or other embedded access links for a specific customer.

### Knowledge Base storage allocation

When **Knowledge Base** is enabled, the UI exposes storage controls such as:

- Storage usage bar
- Allocated Storage (MB)
- Partner Available

The UI also mentions additional storage pricing (example: “\$8/GB”).

## Team management controls

This section also includes:

- **Enable Team Members**
- **Maximum Team Members**
- Team member list (when enabled)

If the portal isn’t enabled yet, the UI may show a notice that team members require customer portal access.

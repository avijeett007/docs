## Where to find it

1. Open **Customers**.
2. Select a customer.
3. Open **Manage**.
4. Go to **Features & Add-ons**.

## Customer Portal toggle

The first toggle is:

- **Enable Customer Portal**

This controls whether the customer can access their own portal.

If portal access cannot be enabled yet, the modal returns an eligibility error instead of silently turning the setting on.

## Add-on feature toggles

The modal currently includes these add-on controls:

- **Advanced AI Analytics**
- **Detailed Call Analysis**
- **Action Point Analysis**
- **API Access**
- **Knowledge Base Processing** - shown as **coming soon**

Notes:

- **Advanced AI Analytics** can be blocked at the partner level until the partner enables that capability first.
- **Knowledge Base Processing** is present in the UI but grayed out as coming soon.

## Premium add-ons

The same panel also includes premium add-ons.

At the moment, the customer modal includes:

- **Twitter / X Integration**

This is presented as a paid add-on with customer-level billing.

## AI Credit Management

The AI credit section includes:

- **AI Credits Enabled**
- **Enable Notifications**
- **Low Credit Threshold**

Turning on **AI Credits Enabled** changes pricing behavior for that customer.

When enabled:

- The customer is charged using **AI Credits** instead of dollar pricing
- **Show Pricing Information** is forced off
- The customer becomes eligible for **AI Gateway** menu visibility

Low-credit notifications:

- Whitelabel email alerts can be enabled
- The threshold is configured in **credits remaining**

Important dependency:

- If **AI Credits Enabled** is turned off again, **AI Gateway** is also turned off for that customer.

## Pricing information visibility

The panel also includes:

- **Show Pricing Information**

This controls whether pricing/cost information is shown in the customer portal.

Rule:

- If **AI Credits Enabled** is on, **Show Pricing Information** is disabled.

## Menu Visibility Options

You can control which sections appear in the customer portal:

- Knowledge Base
- Integration
- Docs & Media
- Schedule Meeting
- Phone Numbers
- API Keys (requires API Access)
- AI Gateway (requires AI Credits)

### API Keys visibility rule

The **API Keys** menu can only be enabled when **API Access** is enabled.

If **API Access** is turned off:

- The **API Keys** menu is automatically turned off
- The API Keys visibility toggle stays disabled until API Access is turned back on

### AI Gateway visibility rule

The **AI Gateway** menu is a separate toggle from **API Keys**.

It is shown in the customer modal as **AI Gateway** with a **Beta** badge.

The toggle only becomes available when:

- **AI Credits Enabled** is on for that customer

The menu's purpose is:

- Allow the customer to generate their own AI Gateway API keys
- Bill that usage through the customer's **AI Credits**

For the customer to actually see AI Gateway in their portal, the partner must also enable **Customer Self-Service API Keys** in the partner-level [AI Gateway](/partner-portal/ai-gateway) page.

### Billing & Payments visibility

**Billing & Payments** is not controlled by a manual toggle in this panel.

In the customer portal, it appears after the customer has portal credentials / active portal access.

## Embed URLs and portal access

If you plan to generate customer-scoped embed links, first confirm the customer has portal access configured and the account is ready for embedded experiences.

Use [Embed URLs](/partner-portal/customers/embed-urls) when you need widget, iframe, or other embedded access links for a specific customer.

### Knowledge Base storage allocation

When **Knowledge Base** is enabled, the UI exposes storage controls such as:

- Storage usage bar
- Allocated Storage (MB)
- Partner Available

The UI also mentions additional storage pricing (example: “\$8/GB”).

## Team management controls

This section also includes:

- **Enable Team Members**
- **Maximum Team Members**
- Team member list (when enabled)

If the portal isn’t enabled yet, the UI may show a notice that team members require customer portal access.

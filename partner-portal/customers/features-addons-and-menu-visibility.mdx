## Where to find it

1. Open **Customers**.
2. Select a customer.
3. Open **Manage**.
4. Go to **Features & Add-ons**.

## Customer Portal toggle

The section includes:

- **Enable Customer Portal**

This controls whether the customer can access their dashboard.

If the customer is not eligible for portal access, the modal will show an error explaining why.

## Add-on feature toggles

The modal includes toggles for:

- **Advanced Analytics**
- **Detailed Call Analysis**
- **Action Point Analysis**
- **API Access**

These features may be treated as add-ons depending on plan/policy.

## API Keys visibility depends on API Access

There is also a menu visibility toggle for **API Keys**, but it can be disabled if **API Access** is not enabled.

## AI Credit Management

The modal can enable “credits-based” charging:

- **AI Credits Enabled**

When enabled:

- Pricing information display may be disabled (the UI indicates “Disabled when AI Credits are enabled”).

### Low credit notifications

If AI credits are enabled, you can configure:

- **Enable Notifications**
- **Low Credit Threshold**

This sends whitelabel email alerts when the customer’s AI credits run low.

## Pricing information visibility

The modal includes:

- **Show Pricing Information**

Use this when you want the customer portal to show (or hide) pricing/cost info.

## Menu Visibility Options

You can control which sections appear in the customer portal:

- Knowledge Base
- Integration
- Docs & Media
- Schedule Meeting
- Phone Numbers
- API Keys (requires API Access)

### Knowledge Base storage allocation

When **Knowledge Base** is enabled, the UI exposes storage controls such as:

- Storage usage bar
- Allocated Storage (MB)
- Partner Available

The UI also mentions additional storage pricing (example: “\$8/GB”).

## Team management controls

This section also includes:

- **Enable Team Members**
- **Maximum Team Members**
- Team member list (when enabled)

If the portal isn’t enabled yet, the UI may show a notice that team members require customer portal access.

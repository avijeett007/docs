---

## Where to find it

1. Open **Customers**.
2. Select a customer.
3. Open **Manage**.
4. Go to **Embed URLs**.

## What Embed URLs are

Embed URLs are customer-scoped URLs/tokens used to embed Knotie AI experiences into other surfaces.

This can be used for:

- Widgets
- Embedded tools
- Customer-specific embeds

## What you can do

Inside the tab you can typically:

- Create an embed token
- Revoke/rotate a token
- Copy the embed URL

If you’re embedding in a website, keep tokens private.

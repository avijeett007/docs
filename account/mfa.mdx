## Overview

MFA adds an extra layer of security by requiring a second factor during sign-in.

## Recommendation

Enable MFA for all partner accounts that manage customer access, billing, domains, or API keys.

## How to set up

1. Open your account security settings.
2. Choose **Enable MFA**.
3. Scan the QR code using an authenticator app.
4. Save your recovery codes.

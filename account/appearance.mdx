## Change the theme

Use the sun or moon button in the top bar to switch between light and dark mode.

1. Open any Partner Portal page.
2. Find the theme button near **Get Support**.
3. Click **Switch to dark mode** or **Switch to light mode**.

The page updates immediately. Use the same button whenever you want to switch back.

<Tip>
If a page is difficult to read, try the other theme and refresh the page. Contact support if the problem continues.
</Tip>
